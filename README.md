# DisasterVision

DisasterVision is an AI-powered post-disaster intelligence and damage assessment platform built for rapid disaster response.

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

### Backend
- FastAPI
- Python

## Features (Planned)
- Before/After satellite image comparison
- Damage assessment
- Priority impact zone detection
- Operational dashboard
- Report generation

🚧 Currently under active development.
